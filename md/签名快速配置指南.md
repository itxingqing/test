## 📝 完整配置流程

### 一、生成生产凭证

**方式1：使用随机生成**

```bash
# 生成AppId（UUID格式）
APP_ID=$(uuidgen | tr '[:upper:]' '[:lower:]' | tr -d '-')
echo "AppId: app_${APP_ID}"

# 生成AppSecret（64字符随机）
APP_SECRET=$(openssl rand -hex 32)
echo "AppSecret: ${APP_SECRET}"
```

**方式2：使用Java代码生成**

```java
import java.security.SecureRandom;
import java.util.UUID;

public class CredentialGenerator {
    public static void main(String[] args) {
        // 生成AppId
        String appId = "app_" + UUID.randomUUID().toString().replace("-", "");
        
        // 生成AppSecret
        SecureRandom random = new SecureRandom();
        byte[] bytes = new byte[32];
        random.nextBytes(bytes);
        StringBuilder appSecret = new StringBuilder();
        for (byte b : bytes) {
            appSecret.append(String.format("%02x", b));
        }
        
        System.out.println("AppId: " + appId);
        System.out.println("AppSecret: " + appSecret.toString());
    }
}
```

## ⚠️ 常见问题

### Q1: 启动时报错"HKDF盐值未初始化"

**原因：** CryptoUtil的@Component注解未生效

**解决：**
```java
// 确保CryptoUtil类有@Component注解
@Component
public class CryptoUtil {
    ...
}

// 确保在启动类的包扫描范围内
@SpringBootApplication
public class LicenseServerApplication {
    ...
}
```

### Q2: 签名验证总是失败

**排查步骤：**

1. **检查appId/appSecret是否一致**
```sql
-- 查询数据库中的凭证
SELECT app_id, app_secret FROM app_credentials WHERE app_id = 'app_test_001';
```

2. **检查参数排序**
```java
// 服务器端添加日志
log.info("排序后参数: {}", sortedParams);
```

```csharp
// 客户端添加日志
Console.WriteLine($"排序后参数: {sortedParams}");
```

3. **检查timestamp**
```csharp
// 客户端检查系统时间
Console.WriteLine($"客户端时间: {DateTime.UtcNow}");
```

```java
// 服务器检查系统时间
log.info("服务器时间: {}", LocalDateTime.now());
```

### Q3: Redis连接失败

**症状：**
```
Unable to connect to Redis
```

**解决方案1：安装Redis**
```bash
# Docker
docker run -d -p 6379:6379 redis

# Ubuntu
sudo apt-get install redis-server

# macOS
brew install redis
```

**解决方案2：使用本地缓存（仅开发）**
```java
// NonceService会自动降级到本地缓存
// 日志会显示：Redis未配置，使用本地缓存（仅适用于单机环境）
```

### Q4: 客户端报"请求已过期"

**原因：** 客户端和服务器时间不同步

**解决：**
```bash
# Windows
# 设置 -> 时间和语言 -> 日期和时间 -> 立即同步

# Linux
sudo ntpdate pool.ntp.org

# macOS
sudo sntp -sS time.apple.com
```
