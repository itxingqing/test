# 许可证系统快速参考

## 🚀 5分钟快速部署

### 1️⃣ 生成密钥（仅首次）
```bash
cd license-server
mvn exec:java -Dexec.mainClass="com.yourcompany.license.util.KeyGenerator"
# 保存输出的私钥、公钥和盐值
```

### 2️⃣ 配置服务器
```yaml
# application.yml
license:
  server:
    private-key: [粘贴私钥]
    hkdf-salt: [粘贴盐值]
```

### 3️⃣ 转换公钥
```bash
# 运行转换工具，输入公钥Base64，得到XML
dotnet run --project PublicKeyConverter
```

### 4️⃣ 配置客户端
```csharp
// CryptoHelper.cs
private const string SERVER_PUBLIC_KEY = @"
<RSAKeyValue>
  <Modulus>[粘贴模数]</Modulus>
  <Exponent>AQAB</Exponent>
</RSAKeyValue>";
```

### 5️⃣ 启动测试
```bash
# 启动服务器
mvn spring-boot:run

# 创建测试许可证
curl -X POST http://localhost:8080/api/admin/licenses \
  -H "Content-Type: application/json" \
  -d '{"customer_email":"test@example.com","product_name":"Test","max_activations":1,"expires_at":"2026-12-31T23:59:59","features":[]}'

# 客户端激活测试
# 使用返回的license_key在客户端程序中激活
```

## 🔑 密钥管理速查表

| 项目 | 生成次数 | 存储位置 | 是否保密 | 配置位置 |
|------|---------|---------|---------|---------|
| **RSA私钥** | 仅一次 | 服务器 | ✅ 绝密 | application.yml |
| **RSA公钥** | 仅一次 | 客户端 | ❌ 公开 | CryptoHelper.cs |
| **HKDF盐值** | 仅一次 | 服务器 | ✅ 绝密 | application.yml |

### 密钥长度参考
- 私钥Base64：约1700字符
- 公钥Base64：约400字符
- HKDF盐值：88字符

## 🔧 常用命令

### 服务器操作
```bash
# 生成密钥
mvn exec:java -Dexec.mainClass="com.yourcompany.license.util.KeyGenerator"

# 启动服务器
mvn spring-boot:run

# 打包
mvn clean package

# 创建许可证
curl -X POST http://localhost:8080/api/admin/licenses \
  -H "Content-Type: application/json" \
  -d '{"customer_email":"user@example.com","product_name":"MyApp","max_activations":2,"expires_at":"2026-12-31T23:59:59","features":["feature1"]}'

# 查询许可证
curl http://localhost:8080/api/admin/licenses?page=1&size=20

# 吊销许可证
curl -X POST http://localhost:8080/api/admin/licenses/XXXX-XXXX-XXXX-XXXX/revoke
```

### 数据库操作
```sql
-- 查询所有许可证
SELECT license_key, customer_email, expires_at, is_revoked 
FROM licenses 
ORDER BY created_at DESC;

-- 查询激活记录
SELECT a.id, a.license_key, a.activated_at, a.last_heartbeat, a.status
FROM activations a
WHERE a.license_key = 'XXXX-XXXX-XXXX-XXXX';

-- 统计
SELECT 
  COUNT(*) as total_licenses,
  SUM(CASE WHEN is_revoked = 0 AND expires_at > NOW() THEN 1 ELSE 0 END) as valid_licenses
FROM licenses;
```

## 🐛 故障排查

### 问题：服务器启动失败
```bash
# 检查配置
grep "private-key" src/main/resources/application.yml
grep "hkdf-salt" src/main/resources/application.yml

# 查看日志
tail -f logs/license-server.log
```

### 问题：客户端激活失败
```
1. 检查服务器是否运行：curl http://localhost:8080/api/v2/health
2. 检查许可证是否有效：SELECT * FROM licenses WHERE license_key = 'XXX';
3. 检查网络连接
4. 查看客户端异常信息
```

### 问题：签名验证失败
```
原因：服务器公钥配置错误
解决：
1. 重新运行PublicKeyConverter转换公钥
2. 确保完整复制XML格式公钥到CryptoHelper.cs
3. 重新编译客户端
```

## 📝 重要提醒

### ⚠️ 密钥安全
1. **绝不**将私钥和盐值提交到Git
2. **绝不**在公共场合分享私钥
3. **必须**定期备份密钥到离线存储
4. **建议**每年轮换一次密钥

### ⚠️ 初始化
- **初始化 = 生成密钥**，仅首次部署时执行
- 生成后的密钥长期使用
- 密钥丢失需要所有客户端重新激活

### ⚠️ 配置验证
```bash
# 服务器启动后应看到此日志
许可证服务初始化完成

# 如果看到错误，说明配置有问题
HKDF盐值长度必须为64字节  # 盐值配置错误
初始化HKDF盐值失败        # 盐值格式错误
```
